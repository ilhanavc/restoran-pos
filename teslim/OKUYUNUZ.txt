═══════════════════════════════════════════════════════════════
  🚀 HIZLI BAŞLAT
═══════════════════════════════════════════════════════════════

  1) PROJE-TANITIM-Restoran-POS.docx dosyasını açın
     (Projeyi 5 dakikada tanıyın)

  2) Uygulamayı denemek için:
     • uygulama/Restoran-POS-v1.1.0-demo.zip dosyasını çıkarın
     • Çıkan klasörde "Restoran POS.exe" dosyasına çift tıklayın
     • Windows SmartScreen uyarısı çıkarsa:
       "Diğer bilgiler" → "Yine de çalıştır"

  3) Giriş ekranında demo bilgileri ile giriş yapın:
     ┌──────────┬───────────────────┬─────────┐
     │ Rol      │ E-posta           │ Şifre   │
     ├──────────┼───────────────────┼─────────┤

     │ Kasiyer  │ kasiyer@demo.com  │ 123456  │
     │ Garson   │ garson@demo.com   │ 123456  │
     │ Mutfak   │ mutfak@demo.com   │ 123456  │
